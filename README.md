# INSCIENCE — головна сторінка (прототип)

Статичний прототип без збирача: `index.html`, `styles.css`, `main.js`, `assets/`.
Іконки, патерни, лого й фото експортовані з Figma («Brand guidelines» → «Brandbook» / «Desktop») через Фігмошу.

Запуск локально (маски й SVG-спрайт потребують http, не file://):

```bash
python3 -m http.server 5173
```

## Сцени
1. Hero — синій, іконка в «C» змінюється (око → квітка → стрілки → серце); на скролі синій стискається в коло.
2. Про INSCIENCE — текст по словах, ключові слова з брендовими формами.
3. Напрямки — 4 патерни з власним ритмом; клік → фільтр проєктів.
4. Проєкти — фільтр-чипи, флагман Conference + 7 карток.
5. Наш вплив — шахова сітка патернів складається за кроками Форма → Повтор → Накладання → Шар → Патерн; цифри на білих плашках.
6. Новини · 7. Ми у медіа (ховається, якщо < 3 матеріалів) · 8. Партнери (стрічка).
9. Як підтримати — синє коло розширюється, реквізити з «Скопіювати». Футер — лого-стрічка.

Кодування напрямків: Наука для всіх = око · FLOW · синій; Рівність у STEM = квітка · INTERSECTION · лайм;
Наука і бізнес = стрілки · GRID · рожевий; Здоровʼя = серце · DENSITY · фіолетовий.

## Заглушки — замінити перед публікацією
- Реквізити (IBAN, ЄДРПОУ, отримувач) і посилання на онлайн-оплату.
- Матеріали «Ми у медіа», логотипи партнерів (зараз — текстові назви).
- Дата й текст новини; посилання на розділи сайту й соцмережі.
- Цифри впливу — підтвердити з клієнтом актуальність.

## Шрифти
Recht і Fixel Display підхоплюються з системи (встановлені локально).
Для публікації потрібен ліцензований вебшрифт Recht (`@font-face`); Fixel — безкоштовний (MacPaw).
